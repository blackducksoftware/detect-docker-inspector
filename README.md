## Overview ##

Detect Docker Inspector is a Detect inspector that enables Detect to analyze your docker images without running them.
Detect Docker Inspector is invoked by running Detect.

## End-of-Life Notice ##

Black Duck is announcing the planned end of life of the Docker Inspector scanning capability as we continue to invest in more advanced, scalable, and accurate container security through the Black Duck Secure Container Add-on, introduced in 2023.

Docker Inspector will remain available during the transition period but will no longer receive enhancements or feature updates. Customers should plan to transition to Black Duck Secure Container Add-on scanning as the recommended and strategically supported solution for container scanning.

On October 30th 2027, Docker Inspector will reach end of life and will be removed from Detect version 13.0.0. After this date, Docker Inspector will no longer be supported.

See the full announcement [here](https://community.blackduck.com/s/question/0D5Ul00000mhMJRKA2/announcement-end-of-life-notice-docker-inspector).
