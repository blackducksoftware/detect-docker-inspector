## Overview ##

Detect Docker Inspector is a Detect inspector that enables Detect to analyze your docker images without running them.
Detect Docker Inspector is invoked by running Detect.

## End of Life Notice ##

**Overview**

Black Duck is formally announcing the planned end-of-life for the Docker Inspector scanning capability. This change reflects our continued investment in delivering more advanced, scalable, and accurate container security through the Black Duck Secure Container Add-on product which was introduced in 2023.

Docker Inspector will be retired as a supported container scanning method. Customers should begin planning their transition to Black Duck Secure Container Add-on scanning, which is now the recommended and strategically supported solution.

Docker Inspector will continue to function during the transition period, but will no longer receive enhancements or feature updates. **At end of life on Oct 30, 2027, Docker Inspector will be fully removed from Detect version 13.0.0.** Continued use may result in reduced accuracy and will no longer be supported.

See the full announcement [here](https://community.blackduck.com/s/question/0D5Ul00000mhMJRKA2/announcement-end-of-life-notice-docker-inspector).
